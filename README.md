# Interactive To-Do List

A simple and responsive task manager built using HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Press Enter to add a task
- Tasks persist after page reload
- Uses LocalStorage for data persistence

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- DOM Manipulation
- Event Listeners

## How It Works

Users can enter a task and add it to the list. Tasks can be marked as completed or deleted. The tasks are stored in the browser's LocalStorage, so they remain available even after refreshing the page.

## Project Outcome

This project demonstrates basic JavaScript events, DOM manipulation, state handling, and browser LocalStorage.
